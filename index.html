PL/SQL Schema Rules
Trigger: trg_sync_book_availability
Automatically flips book to BORROWED on loan issue, and back to AVAILABLE on return.
Function: calculate_fine()
Computes $2.00/day overdue. Returns $0.00 for on-time returns.
Constraints:
• Suspended members are blocked from borrowing.
• Double-borrowing prohibited.
Books Table (BOOKS)
Book ID Title Author Category Status Action
Members Table (MEMBERS)
Member ID Full Name Email Phone Join Date Status Actions
PL/SQL Procedure: issue_book(p_book_id, p_member_id, p_loan_days)
Business Rule Validations:
1. Member must exist in MEMBERS table.
2. Member must NOT have status 'SUSPENDED' (Try Member #4 Diana Prince to test exception handling).
3. Book must exist and its status must be 'AVAILABLE'.
4. Upon successful issue, trg_sync_book_availability updates book status to 'BORROWED' automatically.
Only books with AVAILABLE status can be issued.
Suspended members will trigger PL/SQL exception: ex_member_suspended.
Default duration is 14 days from today.

                3. Trigger trg_sync_book_availability marks book status back to 'AVAILABLE'.
